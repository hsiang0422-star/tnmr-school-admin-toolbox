在其他電腦安裝

Codex 私人技能：在新電腦登入有權限的 GitHub 帳號，於 Codex 啟用 GitHub 連線；先複製並叫用 $my-github-skills，再從技能卡複製名稱，請 Codex 從私人技能庫安裝或更新。查看完整說明 ↗

Claude Code HyperFrames：在新電腦終端機依序執行 claude plugin marketplace add heygen-com/hyperframes、claude plugin install hyperframes@hyperframes，再重新啟動 Claude Code 或執行 /reload-plugins。查看官方安裝說明 ↗

其他 Claude 私人技能：先登入有權限的 GitHub 帳號，從 私人 Claude 技能庫 ↗ 複製所需技能資料夾，再放入新電腦的 Claude 技能目錄。

Claude Code 外掛市集（可自動更新）：在新電腦終端機依序執行 claude plugin marketplace add hsiang0422-star/claude-skills、claude plugin install moneyprinterturbo@hsiang-skills --scope user；在 Claude Code 輸入 /plugin → Marketplaces → hsiang-skills → Enable auto-update 即可自動更新。查看說明 ↗

技能清單依目前可用 Skills 整理；技能是否能執行，仍依目前 Codex 工作區與外掛狀態為準。
